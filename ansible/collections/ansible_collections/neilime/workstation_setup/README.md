# neilime.workstation_setup

Owns configuration validation and normalization, system and application setup,
secret retrieval, home preferences, developer tooling, and browser/AI adapters.
Roles consume resolved configuration and preserve managed-user ownership,
check-mode behavior, and private credential handling.

- [Configuration](../../../../../docs/usage/configuration.md): overrides, dotfiles, desktop settings, and tools.
- [AI tools](../../../../../docs/usage/ai-tools.md) and [browser profiles](../../../../../docs/usage/browser.md): user contracts.
- [Automation and Bitwarden](../../../../../docs/development/automation.md): authentication and execution boundaries.
- [Browser adapters](../../../../../docs/development/browser-adapters.md) and [AI adapters](../../../../../docs/development/ai-tools.md): extension contracts.
- [Project skills](../../../../../docs/development/project-skills.md): repository-scoped declarations.
- [Development](../../../../../docs/development/README.md): collection boundaries and validation.
