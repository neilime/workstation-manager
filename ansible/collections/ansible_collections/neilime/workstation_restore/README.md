# neilime.workstation_restore

Owns archive validation, safe extraction into the managed home, and Git
reattachment during setup. Invalid archives stop before extraction. Failed Git
recovery stops setup while preserving restored files and recovery overlays.

- [Backup and restore](../../../../../docs/usage/backup-and-restore.md): archive contents, restoration, and recovery limits.
- [Development](../../../../../docs/development/README.md): collection boundaries and validation.
